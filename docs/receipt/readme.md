# Накладні

## 1. Типи

- `regular` — звичайна накладна; позиції можуть іти на склад або на магазини.
- `supplement` — накладна-дозамовлення; усі позиції примусово йдуть на склад.

Тип визначає логіку всієї накладної, тому чекбокса дозамовлення на окремих позиціях немає.

## 2. Проведення накладної-дозамовлення

Перед проведенням працівник вручну обирає одну групу доставки. Стани замовлень і збирання показуються лише як інформація й не блокують вибір.

У транзакції проведення фіксуються:

- `targetDeliveryGroupId`;
- `supplementOpenedAt`;
- `supplementStatus='pending'`.

Після транзакції створюються `SupplementOffer`. Якщо процес зупинився або частина вставок не вдалася, фоновий звірятель повторює створення, доки накладна не стане `supplementStatus='ready'`.

## 3. Повторні накладні

Кожна нова накладна-дозамовлення є окремою хвилею. Повторна накладна для тієї самої групи дозволена. Той самий товар у різних накладних створює окремі пропозиції.

## 4. Сумісність

Поля `supplementClosesAt` та `SupplementOffer.closesAt` лишені лише для читання старих документів. Нова логіка їх не використовує.
