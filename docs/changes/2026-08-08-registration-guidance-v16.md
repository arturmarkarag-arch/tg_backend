# Registration guidance v16

- Уточнено повідомлення для незареєстрованих користувачів.
- Для `not_in_group` прямо вказано обов'язкову групу «Оголошення».
- Користувачу сказано звернутися до менеджера або адміністратора для реєстрації/додавання в групу.
- Після додавання до групи користувачу пропонується повторно відкрити MiniApp або виконати `/start`.
- Тексти синхронізовані між MiniApp, browser login, Bot `/start` та API submit-помилкою.
