# V47.14 — receipt photo comments persistence

`ReceiptItem.photoMeta` now supports multiple independently positioned comments:

```js
photoMeta: {
  comment,      // legacy mirror of first comment
  commentPos,   // legacy mirror of first position
  comments: [
    { id, text, pos: { x, y } }
  ],
  pricePos,
  qtyPos
}
```

`utils/receiptPhotoMeta.js` centralizes normalization, bounds coordinates to 0..1, limits comment count/length, and converts old single-comment rows on read/write without a destructive migration.

Derived Product/ShopProduct label metadata now carries all comment coordinates (and text in the `comments` array), while legacy `commentX/commentY` continues to represent the first comment. Shop-owned notes use newline-joined comment text. Warehouse receipt-derived products also retain comment text/positions so the shared product photo editor can reopen from the clean original without losing multiple annotations.
