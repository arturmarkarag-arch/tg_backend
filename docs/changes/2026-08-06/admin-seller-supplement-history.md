# Дозамовлення в історії продавця

Адміністратор у модальному вікні історії конкретного продавця бачить:

- звичайні замовлення продавця;
- дозамовлення, які цей продавець створив (`SupplementRequest.createdBy`);
- обидва типи в одному хронологічному списку, згрупованому за днями.

Дозамовлення групуються за накладною. Вони доступні тільки для перегляду: кнопка редагування звичайного замовлення для них не показується.

Загальна адмінська історія всіх дозамовлень не створюється.
