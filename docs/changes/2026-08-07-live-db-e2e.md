# 2026-08-07 — Live DB order/picking E2E

Додано production-like E2E harness для перевірки order → picking → closure на реальній MongoDB без реальних покупців.

Нові файли:

- `scripts/liveOrderPickingE2E.js`
- `scripts/liveOrderPickingE2ECleanup.js`
- `docs/operations/live-db-e2e-before-prod.md`

Package scripts:

- `npm run test:live:e2e:preflight`
- `npm run test:live:e2e`
- `npm run test:live:e2e:cleanup -- --runId=<RUN_ID> --execute`

Suite створює тільки synthetic fixtures з per-run marker, перевіряє real HTTP routes, live indexes, transactions, conflict start gate, session isolation, physical route barrier, partial progress, short-pick, OOS, crash recovery, late-order strict reconcile, coverage/unterminated integrity blockers та group/session mismatch diagnostics.

Production Redis навмисно не використовується. Global order-number counter також не витрачається: test process використовує synthetic order numbers. Crash-safe manifest дозволяє exact cleanup конкретного run id.
