# Дозамовлення

## 1. Призначення

Дозамовлення — окремий потік для нових товарів, які треба терміново запропонувати одній вручну вибраній групі доставки.

Дозамовлення не створює, не відкриває повторно й не блокує `OrderingSession`. Єдина бізнесова прив’язка — `deliveryGroupId`.

## 2. Життєвий цикл

```text
open → frozen → completed
```

- `open`: магазини можуть створювати, змінювати й видаляти заявки; склад може ставити галочки `packed`.
- `frozen`: адміністратор або склад вручну закрив прийом; продавці більше не змінюють заявки.
- `completed`: усі заявки товару спаковані або після замороження заявок не було.

Автоматичного закриття за часом немає.

## 3. Накладні та повторні хвилі

Одна накладна типу `supplement` відкриває власну хвилю для однієї групи.

Протягом дня дозволено проводити будь-яку кількість накладних-дозамовлень для тієї самої групи. Якщо в новій накладній є товар, який уже присутній в іншій відкритій або замороженій накладній, нова накладна все одно створює окрему пропозицію.

У межах однієї накладної однаковий `productId` показується один раз, навіть якщо товар внесено кількома рядками.

## 4. Заявка магазину

Одна заявка належить магазину, а продавець зберігається як автор. Унікальна пара:

```text
offerId + shopId
```

Після `packed=true` продавець не може змінити або видалити заявку, доки склад не зніме галочку.

## 5. Віртуальний блок

Віртуальний блок не є фізичною полицею. Він показує активні пропозиції вибраної групи й актуальне фізичне місце товару: `Надходження` або звичайний блок.

Після завершення товар зникає. Коли немає пропозицій `open` або `frozen`, плитка віртуального блока не показується.

## 6. Кількість і нестача

У поточній версії не ведеться резервування або фактичний складський залишок для дозамовлень. Немає OOS, часткового виконання та адміністративного скасування.

Це свідомо відкладено. Див. `docs/architecture/technical-debt.md`.

## 7. Telegram

- стартове повідомлення надсилається після відкриття;
- нагадування надсилаються кожні дві години, поки хвиля `open`;
- назви товарів, ціни та час не виводяться;
- повідомлення про закриття не надсилається;
- URL Mini App береться лише з `supplement.settings.appUrl`.
